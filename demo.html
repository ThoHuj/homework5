Cursor Slash Command: /sync

Forces the agent to pause, self-evaluate against goals, process, and spec — with short evidence.

How it works

Agent working
→
User runs /sync
→
Agent stops & reads PROJECT.md
→
Structured self-check
→
Next step decision

Key rules

Pause immediately Agent must stop current work before answering.
80-char evidence max Every claim needs a short, concrete proof.
Stuck detection Flags loops, useless steps, or being on track.
Actionable output Ends with either a pivot or the next logical step.

Command template

.cursor/commands/sync.md
1. Overall goal: Are we moving in the right direction?
   Status: [Yes / No / Partially]
   Evidence: [Max 80 characters]

2. Process rules: Are we following the development process?
   Status: [Yes / No]
   Evidence: [Max 80 characters]

3. Specification: Does the code/plan meet the specification?
   Status: [Yes / No / Deviation]
   Evidence: [Max 80 characters]

4. Progress & momentum: Are we stuck?
   Assessment: [On track / Stuck in a loop / Useless step]
   Evidence: [Max 80 characters]

5. Next step (Action):
   [If stuck: debugging pivot. If on track: next logical step.]

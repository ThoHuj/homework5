# Ruthlessly critique the current code/plan (/roast)
Biggest rule: Drop all niceties. Be brutally, comically, and creatively critical.
Find every flaw, design issue, questionable decision, smell, or missed opportunity.
Don't offer praise, fixes, or encouragement—just roast in detail.

1. Architecture & Design
- What is convoluted, overengineered, or laughably naïve?
- Which abstractions waste everyone's time? Where is it obviously fragile?
- If it's "clever," explain why that's an insult, not a compliment.

2. Code Quality
- Where is the code unreadable, unmaintainable, or embarrassing?
- Point out styling horrors, logic bombs, naming crimes, and documentation deserts.
- If it mostly works, explain why that sets a low bar.

3. Tests (or lack thereof)
- Is coverage a joke? Are edge cases actively ignored?
- Where do tests enable bugs instead of finding them?
- If there are no tests: mock appropriately.

4. Process & Decisions
- What was obviously rushed or cargo-culted?
- Call out ye olde copy-paste, useless boilerplate, and TODOs older than dirt.
- Which "standards" are performative?

5. Overall Impression
- Make the recipient want to reconsider their career choices (in jest... maybe).
- Wrap up with the most stinging, witty, savage one-liner summary of the whole mess.
